
# Python Web Scraping with Pagination

## Project Overview
This project is developed as part of the Python for Data Engineering & Automation Internship.

The objective is to scrape book product information from a practice website using Python.

## Objectives
- Extract product information from HTML pages.
- Navigate multiple pages using pagination.
- Parse HTML using BeautifulSoup.
- Handle HTTP errors and retries.
- Export structured data into CSV and JSON.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- JSON
- CSV

## Data Extracted
- Product Name
- Price
- Rating
- Availability
- Product URL

## Project Structure
- scraper.py
- products.csv
- products.json
- requirements.txt

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Execute:

   python scraper.py

4. Check the generated CSV and JSON files.
